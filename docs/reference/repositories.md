# Repositories

ReliaForge is split across three repositories. Use this table to find the right code or document.

| Repository | What you will find |
| --- | --- |
| [`reliaforge`](https://github.com/SajoLuo/reliaforge) | Project website, getting-started guides, architecture overview, security overview, and roadmap |
| [`reliaforge-backend`](https://github.com/SajoLuo/reliaforge-backend) | Python backend, management API, example plugins, plugin scaffold, and detailed backend docs |
| [`reliaforge-frontend`](https://github.com/SajoLuo/reliaforge-frontend) | React console, browser API client, UI tests, and the read-only online demo |

For detailed code behavior, use the docs beside that code. Backend and frontend releases have their
own versions; check each repository's tags and GitHub Releases for published changes.
