# 版本与 API

本页列出当前版本使用的版本规则。

## 插件 API

在 `manifest.json` 中把 `api_version` 设为 `"v1"`。如果使用其他值，后端会在导入插件的
Python 入口之前拒绝该插件。

## 插件依赖

每项依赖都包含插件 ID 和可接受的 SemVer 范围。导入插件之前，后端会检查提供者缺失、
版本不匹配和循环依赖。

提供者插件的 SemVer 用来说明它所提供服务的版本。

## 管理 API

控制台使用 `/api/v1`。API 响应发生变化时，请同步修改后端模型和前端解析器，再运行前后端 API
兼容性检查。

## 配置与重启

插件环境变量使用 `RELIAFORGE_<PLUGIN_ID>_` 前缀，用 `__` 表示嵌套字段。重启插件时会重新
读取配置；修改 Python 源码或 `manifest.json` 后，需要重启后端进程。
