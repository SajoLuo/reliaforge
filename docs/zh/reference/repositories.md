# 仓库

ReliaForge 分为三个仓库。可以通过下表找到对应的代码和文档。

| 仓库 | 包含内容 |
| --- | --- |
| [`reliaforge`](https://github.com/SajoLuo/reliaforge) | 项目网站、快速开始、架构概览、安全概览和路线图 |
| [`reliaforge-backend`](https://github.com/SajoLuo/reliaforge-backend) | Python 后端、管理 API、示例插件、插件脚手架和详细后端文档 |
| [`reliaforge-frontend`](https://github.com/SajoLuo/reliaforge-frontend) | React 控制台、浏览器 API 客户端、界面测试和只读在线演示 |

需要确认代码的详细行为时，请查看与代码同仓库的文档。后端和前端分别发布版本，已发布的改动
以各仓库的标签和 GitHub Releases 为准。
